# Staging fill records

Operator journal for verified on-chain fills on **staging** only. Append one file per milestone fill; do not delete prior records.

## Naming

```
staging-fill-records/{YYYY-MM-DD}-first-fill.md
staging-fill-records/{YYYY-MM-DD}-fill-{short-id}.md   # optional follow-up fills
```

## Template

Copy the record block from [staging-first-fill-record-template.md](../staging-first-fill-record-template.md).

Pre-flight: [trade-staging-checklist.md](../../trade-staging-checklist.md).
